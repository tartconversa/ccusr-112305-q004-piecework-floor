# 资料口径

班次号 S 的两位数字是既定工作窗口，最后一位区分同日班次条目。开始和结束是窗口内分钟，同一人在同一窗口的重叠应按实作时间合并。已签字分钟是该条认可的观察量，不代表可以替同一人员的其他登记追加一份工时。capacity_min 是该条存在时可以用于计件的最高分钟。只有已确认复核会修改认可时长。
pack 是配对批，质量单的 accepted_claims 是该版确认应计的工序认领。已完成并支付的原件保留发薪归属，重做工序按实际负责人与有效单价计，不增加该批成对合格数。单价为人民币每对，保底为人民币每工时，抵扣上限按员工的后续月计。仅银行确认算已付款。跨月按工作窗口计算应发和差额，原到账月份以记录为准。

site_assignments 的 effective 是当地工作日，window 的同名值表示同一连续生产窗口。发薪站与实际承担差额的站并行保存。appeals 只按具体认领和工时核复，重新申报不等同于已确认。
bank_legs 包括支付拆笔。payment 指发薪对账单，movement 固定支付拆分身份、record 标明一条状态通知。payments 的汇总回单与 bank_legs 的已到账明细有明示关联时应当相互核对，拆笔不再多计一次从同一回单发出的金额。已确认次期抵扣仍受下一工作月金额上限。
